## 1. 실행·종료(더블클릭)
`C:\Users\user\Projects\safe-school-beta2\scripts\preview\` 폴더에서:

| 파일 | 하는 일 | 언제 |
| --- | --- | --- |
| `preview-start.cmd` | 로컬 DB 확인 → 웹앱 켜기 → 브라우저로 `http://localhost:5000` 열기 | 점검할 때마다 |
| `preview-stop.cmd` | 웹앱 끄기(데이터는 그대로) | 점검이 끝났을 때(또는 시작 창에서 Ctrl+C) |
| `preview-setup.cmd` | 마이그레이션 적용·가상 학교·가상 계정 준비 | 새 기능을 받은 뒤 |
| `preview-reset.cmd` | 로컬 점검 기록을 모두 지우고 처음 상태로(‘초기화’ 입력 필요) | 처음부터 다시 점검할 때 |

- 시작 창(검은 창)은 점검하는 동안 **닫지 마세요.** 닫으면 웹앱이 꺼집니다.
- 스크립트는 매번 **운영 관련 변수를 지우고**, DB 주소가 `127.0.0.1:5432/safeschool_preview` 가 아니면 스스로 멈춥니다.
- 웹앱은 이 PC 안(127.0.0.1)에서만 열립니다. 메일은 실제로 보내지 않습니다(가입 인증코드는 시작 창에 표시되지 않으며, 가입 화면 점검은 화면 문구 확인까지만 권장).

## 2. 여러 계정을 동시에 쓰는 방법
같은 브라우저 창들은 로그인을 공유합니다. 역할마다 **다른 브라우저 또는 다른 모드**를 쓰세요.

| 창 | 권장 계정 |
| --- | --- |
| Chrome(일반) | 학교 관리자 `admin@…` |
| Chrome 시크릿(Ctrl+Shift+N) | 일반 교직원 `staff@…` |
| Edge(일반) | 담임 `teacher11@…` |
| Edge InPrivate(Ctrl+Shift+N) | 안전업무 담당 `safety@…` 또는 교장 `principal@…` |

계정을 바꿀 때는 오른쪽 위 로그아웃 후 다시 로그인합니다. 비밀번호는 `demo-accounts.txt` 에 있습니다.

## 3. PC 화면과 iPhone 크기(390px) 확인
- **PC**: 브라우저 창을 최대화한 상태(가로 1280px 이상)로 확인합니다. 왼쪽 메뉴가 보입니다.
- **iPhone 크기**: 해당 브라우저 창에서 `F12` → `Ctrl+Shift+M`(기기 모드) → 위쪽 기기 목록에서 **iPhone 12 Pro(390×844)** 선택 → 새로고침(F5). 하단 메뉴가 보입니다.
  - 기기 목록에 없으면 'Dimensions: Responsive' 에서 너비 390, 높이 844 입력
  - 끝나면 `Ctrl+Shift+M` 으로 기기 모드 해제
- 실제 iPhone 으로 확인하려면 웹앱을 같은 와이파이에 열어야 해서(외부 접속 허용) 이번 점검에서는 제외했습니다. 필요하면 별도로 요청하세요.

## 5. 문제가 생기면
| 증상 | 확인 |
| --- | --- |
| 시작 창이 '로컬 PostgreSQL 서비스가 꺼져 있습니다' | 윈도우 검색 → '서비스' → `postgresql-x64-16` 시작 |
| '5000번 포트가 이미 사용 중' | 이미 켜져 있음 — 브라우저에서 `http://localhost:5000`, 또는 `preview-stop.cmd` 후 다시 시작 |
| 로그인 실패 | `demo-accounts.txt` 의 이메일·비밀번호 확인(대소문자), 여러 번 틀리면 잠시 후 다시 |
| 화면이 이전 버전 | 브라우저 새로고침(Ctrl+F5) |
