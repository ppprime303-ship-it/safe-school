# Beta PILOT 2 — Phase 1~3 화면 점검 안내(운영 서버 없이 로컬 미리보기)

대상 브랜치 `beta/pilot-2` · 운영 서버·운영 DB를 쓰지 않습니다. 가상 학교·가상 계정·가상 사진만 사용합니다.

## 1. 로컬 미리보기 준비(이 PC에서만)
> 이 PC에는 아직 PostgreSQL·Docker가 없습니다. 아래 둘 중 하나가 필요합니다(설치는 사용자 판단).

**A. PostgreSQL 16 설치(Windows 설치 프로그램)** 후 로컬 DB 하나 만들기(예: `safeschool_dev`).
**B. Docker Desktop** 이 있다면: `docker run --name safeschool-dev -e POSTGRES_PASSWORD=<로컬용 비밀번호> -p 5432:5432 -d postgres:16`

그다음 PowerShell 에서 작업 폴더(`C:\Users\user\Projects\safe-school-beta2`)로 이동해, **이 창에서만 유효한** 환경변수를 지정합니다(서버는 `.env` 를 자동으로 읽지 않음 — 파일에 저장하지 않고, 운영 값은 쓰지 않음):
```powershell
$env:DATABASE_URL = "postgresql://postgres:<로컬용 비밀번호>@localhost:5432/safeschool_dev?schema=public"
$env:SESSION_SECRET = "<32자 이상 아무 문자열>"
$env:DEMO_PASSWORD = "<12자 이상>"
$env:MAIL_PROVIDER = "console"
$env:PORT = "5000"
$env:INCIDENT_UPLOAD_DIR = "C:\Users\user\safeschool-preview-uploads"
```
1. `npm run db:migrate` — 로컬 DB에 마이그레이션 적용(주소가 localhost 인지 다시 확인)
2. `npm run db:seed` — 데모 학교(가상)와 계정(관리자·담임 3·교직원) 생성
3. `$env:PREVIEW_CONFIRM = "local"; npm run preview:setup` — 데모 교장·안전업무 담당 계정 추가(로컬 DB가 아니면 스스로 멈춤)
4. `npm run dev` → 브라우저에서 `http://localhost:5000`
5. 모바일 확인: PC 브라우저 개발자 도구의 기기 화면(390px), 또는 같은 와이파이 휴대폰에서 `http://<PC의 IP>:5000`(방화벽 허용 필요)

계정(비밀번호는 모두 `DEMO_PASSWORD`): `admin@demo.safeschool.invalid`(관리자), `principal@…`(교장), `safety@…`(안전업무 담당), `teacher11@…`·`teacher12@…`·`teacher21@…`(담임), `staff@…`(교직원). 여러 계정은 서로 다른 브라우저(또는 시크릿 창)로 동시에 로그인하세요.

정리: 점검 후 로컬 DB 삭제(`docker rm -f safeschool-dev` 또는 DB 삭제), 업로드 임시 폴더 삭제.

## 2. 점검 순서(권장 시나리오)
### 모의훈련
| # | 계정 | 화면 | 확인할 것 |
| --- | --- | --- | --- |
| 1 | 관리자 | 상황판 → 훈련 발령 | 주황 '훈련 상황 · 실제 아님' 배너 |
| 2 | 교직원 | 아무 화면 | 상단 '모의훈련 안내 · 실제 아님' + **'재난훈련 안내 확인'만**(소재 보고 버튼 없음), 비상연락망 병행 안내 |
| 3 | 담임 | 학급 보고 | 담당 학급만 보고·수정 가능 |
| 4 | 관리자 | 학급 보고 | 담임 학급이 없으면 '보고할 학급이 없습니다' 안내(대리 지정 안내) |
| 5 | 교직원 | 상황판 | 학급별 숫자만(메모·보고자·부상 없음), 발령·종료 버튼 없음 |
| 6 | 관리자 | 상황판 → 대리 보고 | 자기 자신은 후보에 없음, 지정한 교직원만 해당 학급 보고 |
| 7 | 교직원 | 현장 제보 → 새 제보 | '훈련 상황 제보 · 실제 아님', 유형·장소 고르면 비슷한 제보 제안(막지 않음) |
| 8 | 안전업무 담당 | 제보 상세 | 처리 상태 4단계 버튼, 작성자 이름 보임 / 교직원 화면엔 이름·버튼 없음 |
| 9 | 교직원 | 제보 상세 → 사진 첨부 | 첨부 후 '대응 담당자만 볼 수 있음' / 관리자 화면에서 사진 보임·삭제 가능 |
| 10 | 관리자 | 상황 종료 | 학급 보고·제보·정보 추가가 읽기 전용으로 바뀜, 훈련일지 작성 가능 |
