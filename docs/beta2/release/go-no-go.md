## 판정 절차

1. 후보 커밋을 고정하고 해시를 적습니다.
2. 해당 표의 항목에 근거(CI URL, 기록, 승인자와 날짜)를 채웁니다. 실제 이름·이메일은 저장소에 적지 않습니다.
3. 항목이 하나라도 ✅가 아니면 No-Go입니다. 예외는 사용자의 위험 수용을 적어야 합니다.
4. 결과를 `docs/devlog`에 남깁니다.

## 배포 당일 중단 기준

- 대상 스키마·DB·건수가 예상과 다릅니다.
- 백업이 실패하거나 읽히지 않습니다.
- 마이그레이션이 실패합니다.
- Prototype 상태 값이 설치 전 기록과 달라집니다.
- 스왑이 계속 늘거나 앱이 반복 재시작합니다.

중단하면 `beta-environment.md` 5절과 `backup-restore.md`를 따르고, `migrate reset`·스키마 DROP·강제 Push는 하지 않습니다.
