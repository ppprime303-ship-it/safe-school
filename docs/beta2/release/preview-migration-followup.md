1. **사용자 명시 승인**(이번 차트 승인과 별개)
2. 미리보기 앱 중지: `scripts\preview\preview-stop.cmd`. 2026-11-02 점검 때 앱이 켜져 있었고 다른 연결이 4개였습니다.
3. 새 백업: 기존 백업은 Phase 4 적용 **전** 시점이므로 재사용하지 않습니다.
4. 새 복원 DB 이름: 기존 `safeschool_preview_restore_20261102`는 이미 있으므로 덮어쓰지 말고 `safeschool_preview_restore_20261102_b`를 씁니다.

## 5. 복구

- **실패:** 원본을 임의로 복원하거나 고치지 않고 상태를 보고합니다.
- **되돌리기가 필요할 때(별도 승인):** 복원 DB로 비교 후 결정합니다. 함수만 되돌리는 경우 `20261031000000_incident_reports`의 두 함수 정의를 다시 적용하고 새 함수를 제거합니다. Prisma 기록은 `migrate resolve`로 맞춰야 하며 직접 지우지 않습니다.
- **미적용 시 동작:** 최신 코드는 후속 조치를 `이 환경에서는 아직 기록할 수 없습니다`(409)로 거부하고, 다른 기능은 영향이 없습니다.
- **이전 코드와의 호환:** 이전 코드는 새 경로를 쓰지 않아 함수 교체의 영향을 받지 않는 구조입니다. 실제 실행은 시험하지 않았습니다.
