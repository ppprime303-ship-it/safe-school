## 4. 사용 후 설문(참여자 1명당 1회)

| 문항 | 응답 형식 |
|---|---|
| Q1. 기능별 사용 편의성(S1~S6 각각) | 1(매우 어려움)~5(매우 쉬움) |
| Q2. 실제 업무에 도움이 될 것 같습니까 | 1~5 |
| Q3. 체감 업무 부담 변화 | 크게 줄었다 / 줄었다 / 같다 / 늘었다 |
| Q4. 오류나 불편했던 점 | 서술 |
| Q5. 다음 개발에서 개선할 점 | 서술 |

Q3는 **체감 업무경감**이고, 3번 표의 값이 **실측 업무시간 절감**입니다. 보고서에서는 두 가지를 따로 씁니다.

## 5. 집계(제출 보고서용)

| 지표 | 계산 |
|---|---|
| 참여 교직원 수 | 1번 표의 행 수 |
| 실제 사용 완료 인원 | 1번 표에서 '예'인 수 |
| 기능별 수행 횟수 | 3번 표에서 시나리오별 SAFE 방식 완료 행 수 |
| 기존 방식 평균 처리 시간 | 시나리오별 기존 방식 완료 행의 소요 평균 |
| SAFE SCHOOL 평균 처리 시간 | 시나리오별 SAFE 방식 완료 행의 소요 평균(API 대기 포함) |
| 평균 절감 시간 | 기존 평균 − SAFE 평균 |
| 업무시간 절감률 | (기존 평균 − SAFE 평균) ÷ 기존 평균 × 100 |
| 시스템 오류율 | 오류가 발생한 SAFE 수행 수 ÷ 전체 SAFE 수행 수 × 100 |
| 사용 편의성 | Q1 평균(기능별) |
| 업무 도움 평가 | Q2 평균, Q3 분포 |
| 개선점 | Q4·Q5 요약 |

- 두 방식을 모두 완료한 짝만 절감률 계산에 넣습니다.
- 표본 수(n)를 함께 적습니다.
- 표본이 5쌍 미만인 시나리오는 "참고값"으로 표시합니다.
