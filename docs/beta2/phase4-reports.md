# Beta PILOT 2 Phase 4 — 공통 보고서(훈련일지·재난대피 상황보고서)

기존 비상대피훈련일지 서식(`shared/drillLog.ts` `buildDrillDoc`)을 그대로 두고, 같은 칸·같은 순서에 실제 재난용 표제어만 바꿔 **재난대피 상황보고서**를 만듭니다. 서식은 사건의 서버 측 `mode` 로 정해지며 사용자가 고를 수 없습니다(DB 트리거로도 강제).

## 1. 두 보고서 비교

| 항목 | 모의훈련: 비상대피훈련일지 | 실제 재난: 재난대피 상황보고서 |
|---|---|---|
| 서식 키 | `evacuation_drill` | `disaster_real` |
| 제목 | 비상대피훈련일지(재난 유형) | 재난대피 상황보고서(재난 유형) + [실제 상황] |
| 본문 표제어 | 참가인원 / 학생 참가 / 훈련 내용 / 훈련 개요 / 훈련 평가 / 추후 대피훈련 시 반영사항 | 인원현황 / 학생 재실 / 대응 내용 / 상황 개요 / 대응 평가 / 문제점 및 향후 조치 사항 |
| 칸 배치·순서 | 기존 승인 서식 | 같음(표제어만 다름, 테스트로 격자 동일성 확인) |
| 붙임 1 학급별 대피 현황 | 있음 | 있음 |
| 붙임 2 현장 제보·조치 현황 | 있음(제보자 이름 없음, 자유 기재 속 교직원 이름 ○○○) | 같음 |
| 붙임 3 교직원 소재 응답 통계 | **없음**(소재 정보를 수집·조회·출력하지 않음) | 익명 숫자만: 대상·응답·미응답·교내/교외·지원 가능/불가/확인 필요·알림 확인 |
| 발령자·종료자 이름 | 기존대로 표시 | 싣지 않음 |
| 역할 담당자 칸 | 기존대로 교직원 선택·이름 허용 | 직위·부서로 적기(이름이 들어가면 완료·내려받기 422) |
| 작성 권한 | 안전업무 담당(기존 `drilllog.edit` 그대로) | 학교 관리자·안전업무 담당(`realreport.edit`) |
| 열람 권한 | 관리자·교장·교감·안전업무 담당(기존 `drilllog.view` 그대로) | 같음 |

공통: 사건 진행 중에도 작성 중(초안) 보고서를 만들 수 있으며 출력물에는 '작성 중 초안(최종본 아님)'이 붙습니다. 최종본(완료)은 사건 종료 후, 종료 뒤에 다시 불러온 기록으로만 가능합니다. 사건당 보고서 1건, 판 번호 충돌 시 409, 삭제 금지·판 기록은 기존 그대로입니다.

## 2. PDF(인쇄) 결과

- 방식: 편집 화면의 '인쇄 / PDF로 저장(A4)' → 브라우저 인쇄(미리보기 A4 쪽만 출력). 한글(HWPX) 내려받기도 같은 배치로 만듭니다.
- 로컬 점검(머리 없는 Edge, 가상 자료 36학급·제보 19건, `scripts/report-print-check.tsx`):

| 문서 | 문서 쪽 수 | PDF 쪽 수 | 용지 | 글꼴 |
|---|---|---|---|---|
| 비상대피훈련일지(최종본) | 5 | 5 | A4 595×842pt | 맑은 고딕·맑은 고딕 굵게 내장 |
| 재난대피 상황보고서(최종본) | 6 | 6 | A4 | 같음 |
| 재난대피 상황보고서(작성 중 초안) | 6 | 6 | A4 | 같음 |

- 붙임 표 머리글은 쪽마다 반복(`thead`), 행은 쪽 경계에서 쪼개지지 않음, 칸 배경색 유지.
- 점검 중 발견·수정: 긴 제보 요약이 고정 행 높이를 넘쳐 쪽이 밀리던 결함 → 글 길이로 행 높이 계산·높이 합으로 쪽 나눔.
- 알려진 기존 표시: 모의훈련 본문 '추후 대피훈련 시 반영사항' 표제어가 세 줄로 접힘(기존 승인 서식 그대로, 이번에 바꾸지 않음).

## 4. 수동 점검 항목(미리보기 화면에서)

1. 모의훈련 발령 → 진행 중 '훈련일지 만들기' → '작성 중 초안' 배지·완료 선택 불가 안내 확인.
2. 훈련 종료 → '종료 기록 다시 불러오기' 안내 → 완료 저장 → '최종본' 배지, 초안 표시 사라짐.
3. 실제 재난 발령(가상 학교) → 학교 관리자로 상황보고서 만들기, 교장·교감 계정은 열람만(작성 단추 없음).
4. 상황보고서 시스템 기록에 교직원 소재가 숫자로만 나오는지, 이름·교내 위치가 어디에도 없는지.
5. '인쇄 / PDF로 저장(A4)' → 브라우저 인쇄 대화상자에서 용지 A4, 여백 없음(또는 기본), '배경 그래픽' 켜기 → PDF 쪽 수·머리글 반복·한글 글꼴 확인.
6. 상황 개요에 교직원 이름을 적고 완료 → 개인정보 검사 경고(422) 확인 → 지우고 완료.
7. 한글(HWPX) 내려받기: 초안은 파일 이름에 `_작성중초안`, 최종본은 없음. 한글 프로그램에서 열어 배치 확인.
8. 휴대폰 폭에서 미리보기가 화면에 맞게 줄어드는지(인쇄는 원래 크기).

## 5. 미확정 정책(결정 필요)

1. **교장·교감 권한**: 현재 열람만. 최종본 확인·결재(승인) 권한을 둘지 미정(결재 단계는 만들지 않음).
2. **모의훈련 일지 제목**: 지시문의 '재난대피 훈련일지'가 아니라 기존 승인 서식 제목 '비상대피훈련일지'를 유지함. 바꿀지 확인 필요.
3. **역할 담당자 이름**: 모의훈련은 기존 승인 서식대로 이름 허용, 실제 재난은 이름 금지(직위·부서). 모의훈련도 이름을 막을지 확인 필요.
4. **보고서 작성·수정자 이름**: 보고서 상세 API는 기존처럼 작성자·최종 수정자·판별 수정자 이름(감사 기록)을 열람 권한자에게 반환함. 보고서 문서(인쇄·HWPX)에는 싣지 않음. 실제 재난에서 이것도 숨길지 확인 필요.
5. **미리보기 DB 마이그레이션**: `20261101000000_disaster_reports`(비파괴: 함수 교체·CHECK·트리거 추가, 자료 삭제·변경 없음)는 테스트 DB에만 적용함. `safeschool_preview` 적용은 별도 승인 후.
6. 보고서 보관 기간·외부 제출 양식은 정하지 않음(운영 정책으로 임의 확정하지 않음).
