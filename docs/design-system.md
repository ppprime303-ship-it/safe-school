# SAFE SCHOOL 디자인 시스템

공공업무용 웹앱의 원칙인 가독성, 직관성, 높은 시인성, 빠른 업무 처리를 따릅니다. 장식과 애니메이션은 쓰지 않습니다. 로딩 표시만 예외이며, '움직임 줄이기' 설정을 켜면 그것도 멈춥니다.

미리보기: 개발 서버 실행 후 `/design` (로그인 불필요, 가상 데이터만 사용)

## 4. 업무경감 UX 규칙

- 로그인 후 소속이 하나면 학교를 자동으로 선택하고, 관리자는 상황판, 교직원은 학급 보고 화면으로 바로 갑니다.
- 학급 보고는 3단계입니다. 화면을 열면 담당 학급과 재적이 자동 표시되고, '전원 대피 확인' 1번이나 대피 확인 인원만 조정한 뒤 보고합니다. 미확인 인원은 자동으로 계산합니다. 결석·부상·메모는 필요할 때만 펼칩니다.
- 학급이 하나면 학급 선택 단계가 없습니다.
- 확인 창은 실제 발령, 외부 발송, 삭제, 상황 종료에만 띄웁니다. 보고와 수정에는 띄우지 않습니다(이력이 남고 고칠 수 있음).
- 서버 응답 전에는 '저장 완료'를 표시하지 않습니다. 통신 장애 시에는 '미전송'으로 기기에 보관하고, 연결되면 같은 요청으로 자동 재전송합니다.
- 상황판은 5초마다 갱신합니다. 실패하면 숫자를 지우지 않고 마지막 갱신 시각과 '연결 끊김'을 표시합니다.
- 위험한 학급(미확인 → 부상)을 상단 목록에 먼저 모읍니다.

## 5. 확장 방법

새 화면은 `AppShell`로 감싸고, 위 컴포넌트와 토큰 이름만 사용합니다. 색상 값(#…)을 화면 코드에 직접 쓰지 않습니다.
