## 2. 목록 화면(`/s/<학교ID>/education`)
1. 제목 '안전교육 자료 찾기'와 보조 문구 '학교 안전교육에 필요한 공식 자료 제공처를 찾아보세요.'
2. 안내 '교육자료는 각 기관의 공식 사이트에서 제공됩니다.'와 작은 보조 글자 '이 화면에서는 교육 이수·실적을 기록하지 않습니다.'
3. 검색·필터를 한 상자로 묶음
   - 사이트·주제 검색
   - 학교급(전체 학교급 / 유치원·초등학교·중학교·고등학교)
   - 안전교육 영역(전체 영역 / 7대 영역)
   - 640px 미만에서는 두 드롭다운을 세로로, 그 이상에서는 나란히 놓습니다.
   - 값을 고르면 테두리와 글자가 남색으로 바뀌어 선택 중임을 알 수 있습니다.
   - 기본 `<select>`와 `<label>`을 써서 키보드와 스크린리더로 쓸 수 있습니다.
4. '자료 제공처 N곳'. 조건이 있으면 '필터 초기화'가 보입니다. 결과가 없으면 '현재 확인된 자료가 없습니다'와 초기화 단추를 보여 줍니다.
5. 간결한 카드: 768px 미만 1열, 이상 2열
   - 학교안전지원시스템 · 안전교육 자료실 / 학교안전공제중앙회 / [유·초·중·고] [7대 안전교육 영역] →
   - 국민안전교육플랫폼 / 행정안전부 / [유·초·중·고] [생활·교통·재난 외] →
   - 카드 전체가 링크 하나이고, 안에 다른 단추가 없습니다.
   - 마우스를 올리면 테두리와 배경이 바뀌고, 키보드로 이동하면 초점 테두리가 보입니다.
6. 하단: 외부 사이트 이용 안내(출처, 이용 조건, 새 창, 개인정보 미전송)를 짧게 표시

**기관 아이콘**: 공식 로고는 사용 허가를 확인하지 못해 쓰지 않았습니다. 같은 크기와 바탕의 디자인 시스템 아이콘을 씁니다(학교안전공제중앙회는 학교 모양, 행정안전부는 방패 모양). 외부 이미지를 불러오지 않으므로 로딩 실패도 없고, 기관명은 항상 글자로 표시합니다.

## 3. 상세 화면(`/s/<학교ID>/education/<기관ID>`)
위에서 아래 순서로 다음을 표시합니다.
1. 목록으로 돌아가기
2. 기관 아이콘, 사이트명, 운영 기관
3. 사이트 소개
4. 추천 학교급
5. 관련 안전교육 영역(전체 배지와, 근거가 있는 경우 영역별 찾는 방법)
6. 제공 교육자료 유형
7. 교육자료를 찾는 방법
8. 자료실 위치: 학교안전지원시스템은 '안전교육 > 자료실 > 7대안전 탭'입니다. 국민안전교육플랫폼은 메뉴 주소를 확인하지 못해 홈페이지로 연결한다고 밝혔습니다.
9. 연결 주소: 방문 단추가 자료실로 바로 가는지 홈페이지로 가는지 표시, 기관 홈페이지 글자 링크(자료실과 다를 때만), 링크 확인일, 분류 근거(펼쳐 보기)
10. 외부 사이트 이용 안내
11. **'공식 사이트 방문'** 강조 단추 하나(새 탭, `rel="noopener noreferrer"`, `referrerPolicy="no-referrer"`)

- 없는 기관 ID면 '찾는 자료 제공처가 없습니다'와 '목록으로 돌아가기'만 보여 주고, 외부 링크는 만들지 않습니다.
- 허용되지 않은 주소면 방문 단추 대신 '링크 확인 필요'를 표시합니다(기존 검사 그대로).
- 접근 권한은 목록과 같습니다. 로그인하지 않으면 `/login`, 승인 대기이면 `/schools`로 이동합니다.

## 4. 검색어·필터 상태 유지
- 목록 주소 쿼리에 `?q=<검색어>&level=<학교급>&area=<영역>`을 씁니다. 필터를 바꿀 때마다 `history.replaceState`로 주소만 바꿔서 방문 기록이 쌓이지 않습니다.
- 카드의 상세 주소에는 현재 쿼리를 붙입니다. 상세의 '목록으로 돌아가기'는 같은 쿼리로 목록을 엽니다.
- 브라우저 뒤로 가기를 누르면 목록 주소(쿼리 포함)로 돌아가 같은 상태가 됩니다. 목록이나 상세에서 새로고침해도 쿼리로 다시 복원합니다.
- 쿼리 값은 허용 목록으로 다시 확인합니다. 알 수 없는 학교급·영역은 '전체'로 바꾸고, 검색어는 50자까지만 받으며, 다른 매개변수는 버립니다.
