# SAFE SCHOOL 심사위원 체험 안내(초안)

> 초안입니다. 접속 주소와 계정은 서버 준비가 끝난 뒤 채웁니다. 비밀번호는 이 문서에 적지 않고 따로 전달합니다.

## 접속
- 주소: `https://<시연 도메인>`(PC·휴대폰 브라우저)
- 계정: 심사위원마다 1개(`judgeN@judge.safeschool.invalid`), 비밀번호는 따로 전달
- 공용 PC에서는 로그인할 때 '공용 기기'를 선택하세요(8시간 또는 30분 미사용 시 자동 로그아웃).

## 이 환경에 대해
- 심사위원마다 **독립된 가상 학교**가 있습니다(SAFE SCHOOL 심사 시연 A~E초등학교). 다른 심사위원의 발령·보고와 섞이지 않습니다.
- 학교·교직원·학생 정보는 모두 가상입니다. 학급에는 인원 수만 있습니다.
- 실제 기관으로 경보·문자·메일을 보내지 않습니다. '실제 상황' 발령도 이 가상 학교 안에서만 기록됩니다.
- 공식 재난 경보 연동은 아직 하지 않았습니다. 그래서 경보함이 비어 있을 수 있습니다(모의 경보 기능은 개발 환경에서만 작동).
- SAFE SCHOOL은 K-에듀파인 등 공식 행정시스템이나 법정 보고를 대체하지 않는 보조 서비스입니다.

## 추천 체험 순서(약 10~15분)
1. **상황판**: 지난 모의훈련 1건(미보고 학급 1개 포함)이 기록되어 있습니다.
2. **훈련 발령**: 상황판 → '훈련 발령'(유형·대피 장소 입력) → 진행 중 배너가 표시됩니다.
3. **학급 보고**: '학급 보고'에서 학급을 골라 대피 인원·부상을 입력합니다. 관리자는 대리 보고를 할 수 있습니다. 미보고 학급은 '완료'로 표시되지 않습니다.
4. **상황판 확인 → 종료**: 미확인·부상·미보고를 확인한 뒤 종료합니다.
5. **훈련일지**: 종료된 훈련으로 훈련일지를 만들고 → 내용 보완 → **HWPX(한글)** 내려받기
6. **교직원·업무**: '교직원' 화면에서 업무 담당자 지정 화면을 봅니다(비밀번호 재확인).
7. **안전교육 자료 / 시설 안전 자료**: 학교급·영역으로 공식 자료를 찾고, 상세에서 공식 사이트로 이동합니다. 시설 자료는 관할 교육청을 먼저 보여 주고, 최근 개정 법령을 맨 위에 표시합니다.

## 역할별 권한(안내용)
| 역할 | 할 수 있는 일 |
| --- | --- |
| 학교 관리자(앱 운영) | 교직원 승인·배정, 학급·재적, 업무 담당자 지정, 발령·종료, 상황판 |
| 안전업무 담당 | 발령·종료, 상황판, 훈련일지 작성·수정 |
| 교장·교감 | 발령·종료, 상황판, 훈련일지 열람(교직원 승인은 앱 운영담당만) |
| 담임교사 | 배정된 학급 보고, 경보함·안내문·자료 열람 |
심사 계정은 '학교 관리자 + 안전업무 담당'이라 위 기능 대부분을 혼자 체험할 수 있습니다.
