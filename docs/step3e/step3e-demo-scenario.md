# STEP 3-E 시연용 시나리오 초안(가상 데이터 · 실시는 앱 개발·최종 검수 완료 후)

이 문서는 **초안**입니다. 실제 교직원 시연·설문·평가는 이번 단계에서 하지 않습니다(사용자 결정).
모든 이름·학교·인원은 가상입니다. 실제 학생·교직원 정보, 실제 경보·문자 발송, K-에듀파인 연동은 없습니다.

## 준비(시연 DB — 사용자 승인 후)
| 계정(가상) | 역할 | 쓰는 화면 |
| --- | --- | --- |
| 가상 교장 | 교장(직책) | 발령, 상황판, 훈련일지 열람·내려받기 |
| 가상 교감 | 교감(직책) | 종료, 상황판 |
| 가상 안전담당 | 안전업무 담당(업무) | 발령·종료, 훈련일지 작성 |
| 가상 담임(2~3명) | 담임 | 학급 보고(휴대폰) |
| 가상 앱 운영담당 | 앱 운영담당(업무) | 교직원 승인, 업무 지정 |
학급 4개 이상, 그중 1~2개는 일부러 보고하지 않아 '미보고' 처리를 보여 줍니다.

## 장면 1. 지진 모의훈련(약 10분)
1. 교장이 PC에서 '지진·훈련' 발령 → 담임 휴대폰에 담당 학급 보고 화면이 바로 열림
2. 담임 A: 대피 23·부재 1 보고(미확인 1 자동 계산) → 다시 확인 후 24로 수정(이력 남음)
3. 담임 B: 부상 1명 포함 보고, 담임 C: 보고하지 않음
4. 상황판에서 미보고 학급·미확인·부상 확인 → 교감이 종료
5. 안전담당이 '훈련일지 만들기' → 학급별 현황이 자동으로 들어감(미보고는 0명이 아니라 '미보고')
6. 교직원 명단에서 역할 담당자 선택, 참가 인원·소요 시간·평가 O/X 입력 → 저장(판 번호)
7. 한글(HWPX) 내려받기 → 한글에서 열어 본문 1쪽 + 붙임 확인

## 장면 2. 실제 상황 구분(약 3분)
1. '실제 상황' 선택 시 확인 문구 입력 → 화면 상단이 빨간 '실제 상황'으로 바뀜
2. 종료도 확인 문구 필요
3. 실제 상황은 훈련일지를 만들 수 없음(훈련 기록과 섞이지 않음)

## 장면 3. 공식 경보(모의)와 안내문(약 3분)
1. 모의 폭염경보 수신 → 경보함에 '[모의]' 표시, 같은 경보 재송출은 1건으로 묶임
2. 경보에서 '안내문 작성' → 예시문 불러와 수정 → 저장(발송은 학교 기존 채널로 직접)
3. 경보는 학교 재난 발령을 자동으로 만들지 않음을 설명

## 시연 때 꼭 말할 것
- 앱은 학교 기존 결재·발송·비상대응 절차를 대체하지 않습니다.
- 자동 테스트 통과는 보안 인증이나 정식 도입 승인이 아닙니다.
- 공식 경보는 모의 데이터입니다.

## 평가 준비 메모(설계는 별도 승인 후)
- 의견만 받고 개인정보는 받지 않음
- 측정 후보: 보고 완료까지 걸린 시간, 훈련일지 작성 시간(기존 방식과 비교는 같은 조건에서만)
- 결과는 측정 후에만 기록(예상치를 결과로 쓰지 않음)
