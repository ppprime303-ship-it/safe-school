## 나이스 인증키 실호출(사용자 실행)
- `E10`: 98건 파싱, 2건 제외, HTTP 500 재현 안 됨.
- `NEIS_CONTRACT.verified=true`는 정상 응답 구조까지만 뜻함. 2건 제외 원인은 건수만 남아 미확인. 앱이 나이스를 호출하지 않아 Beta 영향 없음. 추가 호출 없음.

## Beta 배포 준비
- `beta.env` 예시의 `DATABASE_URL`에 따옴표 추가. 없으면 셸로 불러올 때 `&`에서 잘려 주소가 사라짐(가짜 값으로 재현).
- `beta.caddy.example`에 접근 제한(`basic_auth`) 추가. 시연 계정이 같은 비밀번호를 쓰기 때문. 이 PC에 Caddy가 없어 `caddy validate`는 서버에서 확인 필요.
- 미리보기 DB 대기 마이그레이션 2개는 Beta 차단 요인이 아님. Beta는 새 DB에 15개를 처음부터 적용.
- 서버 접속·DB 변경·마이그레이션·실제 API 호출·푸시·배포 없음.
