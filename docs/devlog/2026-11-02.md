## 최종 배포 차단 항목 정리
- 인증코드 저장을 SHA-256에서 서버 비밀키 파생 HMAC으로 변경(사용자·목적·코드). 운영에서 비밀키가 없으면 503. 만료·시도·재전송 규칙은 그대로. 변경 전에 발급한 미사용 코드와 비밀키 교체 전 코드는 무효.
- 삭제 설계안 `docs/beta2/release/privacy-deletion-design.md` 작성(미구현·미실행). 일괄은 Beta 환경 전체 폐기, 개인 요청은 가명 처리를 권장.
- 공공 API 권한 표 추가. 체크리스트를 G1·G2로 재구성.

## 전교 대피 현황 차트
- 상황판에 단일 차트 추가(전교 전체 행 + 실제 있는 학년 행, 가로 누적 막대). 위치는 핵심 수치·위급 학급 아래, 학급별 상태 위.
- 기존 상황판 응답(`classes`)을 화면에서 집계. 새 API·폴링·DB 변경·라이브러리 없음.
- 대피 완료 = 보고된 대피 확인, 대피 미완료 = 보고된 미확인 인원, 확인되지 않음 = 미보고 학급 재적. 사전 부재는 대상에서 제외. 완료율은 내림, 재적 미상 미보고 학급이 있으면 집계 불가, 보고가 없으면 확인 중. 학급 보고율은 따로 표시.
- 초록·회색은 차트 전용 색 토큰 추가(기존 완료 토큰은 청록색).
- `safeschool_test` 임시 서버와 머리 없는 Edge로 390·1366 배치 확인. 사람 확인은 점검표 29~33번.
