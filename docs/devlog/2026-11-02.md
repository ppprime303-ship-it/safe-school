## T3 Beta 환경 분리

## T4 사진 업로드
- 감사 결과: 기존 systemd 읽기 전용 경로·기본 저장 경로·Caddy 1MB가 앱 정책과 충돌.
- 사진 본문은 세션·요청 제한·동시 처리 수·학교 소속 확인 뒤에 읽음(이전에는 인증 전 7MB까지 파싱).
- Caddy 예시 `deploy/caddy/beta.caddy.example`: 사진 POST만 7MiB, 그 밖 1MB.
- `deploy/scripts/beta-backup.sh`: DB 덤프 + 사진 묶음. 가짜 도구로 흐름·거부만 시험, 실제 DB 미실행.
- 첫 시험에서 동시 처리 상한 4는 10건 동시 요청에 503 발생 → 메모리 추정(건당 약 20MB)에 맞춰 8로 조정. 실측 필요.

## T5 동시 보고

- 429에 `Retry-After`·`retryAfterSec`, 화면에 대기 시간과 비상연락망 병행 안내. 학급 보고는 입력 보관 후 같은 요청 번호로 자동 재전송(자동 재전송 화면 동작은 자동 테스트 없음).
- `tests/beta2-shared-ip-limit.test.ts`: 공인 IP 하나에 교직원 70명, 모의훈련·실제 재난.

## Phase 4 화면·기능 통합 검증
- 환경: 로컬 미리보기(개발 모드), 머리 없는 Edge를 CDP로 제어. 390px는 브라우저 모바일 에뮬레이션(실제 iPhone 아님).
- 시험 자료: 표시 `BETA2_TEST_20261102`가 붙은 새 가상 사건 4건과 그 보고서만 추가. 기존 행 113개는 해시 기준 변경 없음. 시험 자료는 삭제하지 않음.
- 결과: API·권한·화면 검사 통과, DB 규칙은 되돌리는 트랜잭션에서 거부 확인. 일지 PDF는 A4·쪽 수 일치·맑은 고딕 내장 확인.
- 발견·수정한 결함
  - 재난대피일지 화면에 '훈련 발령', '교직원 참가', '학생 참가', 훈련 입력 예시가 남아 있음 → `editorLabels`, `timeBasisNote`로 서식별 분리.
  - 보고서 오류 문구 일부가 실제 재난에도 '훈련일지'로 표시됨 → '보고서'로 변경.
  - 소재 화면 요약 링크 높이 20px → 터치 영역 확보.
- 수정하지 않은 사항
  - 소재 보고 양식이 알림 이력 아래에 있어 이력이 쌓이면 스크롤이 길어짐(Phase 4 범위 밖, 판단 필요).
- 미확인: HWPX를 한글 프로그램에서 열어 보는 확인, 생성된 PDF 파일을 뷰어로 여는 확인, 실제 휴대폰, 미리보기의 교감 계정(가상 계정 없음, 자동 테스트로만 확인), 미리보기의 다른 학교 실데이터 격리(학교 1곳뿐, 자동 테스트로 확인).

- Phase 5~7 마이그레이션 없음. `safeschool_preview`는 이번 작업에서 접속·변경하지 않음.

## 최종 배포 차단 항목 정리
- 인증코드 저장을 SHA-256에서 서버 비밀키 파생 HMAC으로 변경(사용자·목적·코드). 운영에서 비밀키가 없으면 503. 만료·시도·재전송 규칙은 그대로. 변경 전에 발급한 미사용 코드와 비밀키 교체 전 코드는 무효.
- 삭제 설계안 `docs/beta2/release/privacy-deletion-design.md` 작성(미구현·미실행). 일괄은 Beta 환경 전체 폐기, 개인 요청은 가명 처리를 권장.
- 공공 API 권한 표 추가. 체크리스트를 G1·G2로 재구성.

## 사용자 직접 검증 반영
- 사용자 확인(변경 전 기준): 앱 실행·로그인, 재난대피일지 HWPX, PDF, 프린터 인쇄, 390px 정상. 비상대피훈련일지 HWPX는 열리나 제보 섹션 삭제 요청.
- 비상대피훈련일지: 현장 제보 붙임 제거, 붙임 번호 정리(스냅숏에도 수집 안 함, 이전 저장본도 출력 안 함). 모의훈련 제보 원본은 제보 화면에 보존.
- 처리 상태: 접수·확인 중·조치 중 → 조치 대기, 조치 완료 → 조치 완료로 표시만 변경. 저장값·API·이력·감사 기록 유지, 마이그레이션 없음. 담당자 화면 단추는 두 개.
- 재난대피일지 붙임 2: 시각·장소·제보 내용·처리 상태. 보고서에서는 원본 상태를 바꾸지 않음, 제보 화면으로 연결.
- 남은 판단: 사건 종료 후 제보 상태 변경 불가(기존 DB 규칙). 바꾸려면 트리거 변경 마이그레이션 필요.
