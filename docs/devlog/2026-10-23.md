## 4. 개발 중 발생한 문제와 해결
| 문제 | 원인 | 해결 |
| --- | --- | --- |
| `e2e:step3e`가 Replit에서 실패 | 대문자가 섞인 테스트 이메일이 DB 제약(`email = lower(email)`)에 걸림 | 테스트 데이터만 소문자로 생성. 제약과 인증 로직은 바꾸지 않음 |
| 모바일 업무 담당자 행 겹침 | 이름·배지·단추가 한 줄에서 공간을 다툼 | 이름 / 현재 업무 / 단추 영역으로 나누고 모바일에서는 단추를 한 줄에 하나씩 |
| 배포 버튼을 누르면 빈 `public` 스키마에 연결될 위험 | 배포용 `DATABASE_URL`에 schema가 없음 | `DEPLOY_PROFILE`·`DEPLOY_DB_SCHEMA` 필수, 허용 목록 검증 |
| STEP 4 첫 화면 정보 과다 | 카드에 모든 설명·근거·링크를 표시 | 간결한 카드와 내부 상세로 나눔 |
| STEP 4 상세에서 긴 사이트명이 320px 카드 테두리에 닿음 | 한국어 낱말 줄바꿈 금지(`break-keep`) | 모바일에서는 아이콘과 제목을 세로로 배치하고 긴 낱말은 줄바꿈 허용. 자동 점검 항목에도 추가 |
| 교육청 수가 17개가 아님 | 2026-07-01 광주·전남 교육청 통합(교육부 목록 16곳) | 16곳으로 구현하고, 이전 이름은 통합교육청으로 연결 |
| 학교 관할 교육청 정보가 화면에 없음 | 학교 정보에는 저장되어 있으나 `/auth/me`가 내려주지 않음 | 기존 응답에 `eduOfficeName` 필드 1개 추가(새 API 아님) |
| 모바일 머리글 공간 부족 | 단추를 하나 더 넣으면 320px에서 STEP 3 화면 제목이 잘림 | 머리글 단추는 하나로 두고 두 자료 화면 위에 탭을 둠 |
| 다수 교육청 누리집 자동 조회 불가 | 사이트의 자동 조회 차단, 스크립트로 그리는 화면 | 확인한 범위만 등급(A/B/C)으로 등록, 미확인 목록 기록 |

## 8. 미해결 사항
- `.replit`의 배포 실행 줄을 `npm run deploy:start`로 바꾸고, 배포 Secrets에 `DEPLOY_PROFILE`·`DEPLOY_DB_SCHEMA`를 넣는 일(사용자 수동 작업, 반영 여부 미확인)
- 시연 학교 DB에 관할 교육청 정보가 없음. 시연에서는 '이 기기에서 선택'으로 동작합니다. 사용자는 인천광역시교육청을 선택한 화면을 확인했다고 알려 주었습니다([사용자]).
- 교육청 15곳은 시설 지침 원문을 확인하지 못함(C 등급). 충남교육청은 https 접속 확인이 필요합니다.
- 교육시설안전 인증 관련 행정규칙은 찾지 못함. 고시 3건은 확인한 판 이후의 개정 여부를 확인하지 못함.
- ChatGPT 공유 링크(2026-10-23)의 대화 본문을 확보하지 못함. 16:20~16:30에 세 번 시도했으나 일반 조회로는 제목('대회 참가자격 검토')만 보였고, 이 작업 세션에는 연결된 브라우저가 없었음. 그래서 포트폴리오의 ChatGPT 관련 내용과 '프롬프트 원문 미확보' 표시는 **미검증으로 유지**함. ChatGPT 데이터 내보내기 파일이나 대화 본문을 첨부하면 대조해서 갱신할 예정
- 이전 결정 대기 항목: 학교 내부 재난과 안내문 연결, 대리 보고 권한 범위, 훈련일지 서식 폭, `db:migrate` 검증
