| 로컬 DB 비밀번호 | 저장소 전체에서 일치하는 문자열 없음(검사함). 저장소 밖 `secrets/`에만 |
| 토큰·API 키·개인키·비밀번호 포함 DB 주소 | 변경분·새 파일에서 발견 없음. `.env` 파일 없음(`.env.example`만) |
| 개인정보 | 가상 학교·`*.invalid`·`school.example` 주소만 |

### 10-4. Windows·Linux 동작
| 항목 | Windows(학교 PC) | Linux(VPS·Replit) |
| --- | --- | --- |
| `npm ci` | 확인(npmjs 주소) | **미확인** — lock의 `registry.npmjs.org` 주소는 npm 기본 동작으로 Replit 패키지 방화벽 주소로 바뀌어야 함. Replit·VPS에서 `npm ci` 확인 필요 |
