## 3. 바뀌지 않은 핵심 원칙

공식 체계를 대체하지 않는 보조 시스템, 학생 실명 미수집, 학교 간 데이터 격리, 감사 로그 추가만 가능, 발령 시점 재적 스냅숏, 미확인은 서버 계산, 마이그레이션은 추가만, 실측하지 않은 단축 시간을 주장하지 않는 실증 원칙, Replit Agent 미사용.
