# 비식별 처리 기록

## 원칙
- GitHub에는 비식별 처리본(`sources/`)만 올립니다. 원본은 비공개 ZIP으로 사용자에게 전달하고 GitHub에 올리지 않습니다.
- 처리 대상 외의 글자는 바꾸지 않습니다(원문 보존). 각 파일 맨 위에 처리본임을 표시했습니다.

## 치환 규칙과 건수(2026-10-20 처리)
| 대상 | 바꾼 표시 | 건수 | 비고 |
| --- | --- | --- | --- |
| 이메일 형식 문자열 | `[이메일 비공개]` | 34 | 모두 Replit 테스트 오류 출력 속 **테스트용 가상 주소**(`…@a.kr`)가 반복된 것. 실제 개인 이메일은 이번 공개 자료에 없었음. 예시 도메인(example.com 등)과 공고문 담당 주소는 유지 |
| GitHub 계정명 | `[GitHub 계정]` | 11 | 개인 이메일과 연결된 계정명 |
| 작업공간 첨부 경로 | `[첨부]/` | 8 | 내부 경로 |
| DB 호스트 이름 | `[DB 호스트 비공개]` | 4 | Replit Prisma 출력 |
| Claude 세션·문서 링크, Replit 미리보기 주소 | 각각 비공개 표시 | 0 | 이번 공개 자료에는 없었음(규칙만 적용) |

## 처리 결과 확인
- 공개 자료에서 남은 이메일 형식은 `teacher01@example.com`, `teacher02@example.com`(예시용 가상 계정)뿐입니다.
- 비밀번호, 인증코드, 쿠키, API 키, 실학생·실교직원 정보는 공개 자료에서 발견되지 않았습니다(테스트 코드의 가상 비밀번호 문자열은 저장소 코드에 원래 있는 값).
- 비공개 원본 중 `90_Claude_세션원본/session.jsonl`에는 계정 이메일이 들어 있습니다. **공유하지 마세요.**
