## 4. 오늘 발견한 실제 버그

**현상:** 학교 소재지를 경보 수집 이후 설정했을 때 동일 내용의 재송출 경보가 별도 항목으로 표시됩니다.

ChatGPT가 GitHub 코드를 확인한 결과 다음 원인이 유력합니다.

`server/src/services/alerts.ts`

`confirmSchoolRegion()` 함수에서 `undetermined` 경보를 `target`으로 재분류하지만, `duplicateOfAlertId`를 다시 계산하지 않습니다.

반면

`server/src/alerts/collector.ts`

최초 경보 수집 과정에서는 `contentHash`, 발령 시각 및 재송출 판단 로직을 이용해 중복 경보를 묶습니다.

**따라서 학교 소재지를 나중에 설정할 때 기존 경보의 중복 그룹 처리가 누락되는 것으로 분석됩니다.**

추가로 해제 경보가 최초 경보를 참조하는 과정과 실제 화면의 '해제됨' 표시 대상을 확인해 주세요.
