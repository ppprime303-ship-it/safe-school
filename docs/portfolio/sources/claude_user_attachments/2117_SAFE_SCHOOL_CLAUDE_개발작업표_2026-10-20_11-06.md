6. 관리자 권한, 소속 학교 격리, 역할별 API 접근, 재난 유형과 훈련/실제 구분, 감사 로그, 멱등키, 안전한 실패 처리는 기능과 동시에 테스트한다.

8. 외부 국가 경보 API의 실제 사용 가능 여부와 데이터 계약은 공식 문서·키로 확인한다. 인증키가 없을 경우 **가상 경보와 모의 발송을 분리해 시연**하고 실연동 완료라고 표현하지 않는다.
9. 각 작업일 종료 시 변경 파일, 커밋 ID, 실행 테스트, 통과/실패, 재현방법, 다음 작업, 미검증 항목을 기록한다. 테스트를 실행하지 않았으면 통과라고 쓰지 않는다.
