### 3-3. SQL 오류와 수정

초기 조회 시 `created_at`을 잘못 사용하여 `column "created_at" does not exist`가 발생. GitHub Prisma 스키마에 정의된 정확한 감사 날짜 필드는 `at`이다.

```sql
SELECT action, at
FROM safeschool_browser_demo.audit_logs
WHERE action LIKE 'event.%'
   OR action LIKE 'report.%'
ORDER BY at DESC
LIMIT 15;
```

## 5. 업무경감 기획 의도 — 사용자 문제 정의에 근거한 요약

- 학교에서 환경·국가 재난경보가 발생할 때 학부모와 교직원에게 수동으로 내용을 다시 전달하는 반복 업무를 줄이고자 함.
- 단순 전달뿐 아니라 **공식 경보의 원문을 보존한 상태로 학교 자체 안내를 추가**하고자 함.
- 안전업무 매뉴얼 분석에 따라 재난·사고 보고서 초안, 안전교육 실적 자동 취합, 안전점검 및 현장체험학습 체크리스트 등은 후속 단계로 계획.
- 실제 자동 발송은 공식 API 제공 범위, 발송 승인, 학교별 발송 정책, 개인정보 보호, 학부모 수신 동의를 확인한 뒤 단계적으로 진행.
- 아직 실제 학교 업무경감 소요시간을 측정한 자료는 없으므로 정량적 시간 절감 효과를 **성과로 단정하지 않음**.

## 6. 경쟁대회 증거 효력의 한계 및 보완해야 할 파일

1. 실제 Claude 대화 기록 export: 사용자가 Claude에 입력한 메시지와 Claude의 응답을 원문·순서·시각과 함께 확보.
2. 실제 ChatGPT 전체 데이터 export: 이 발췌본 외 대화 누락 여부 대조.
3. GitHub 해당 커밋 SHA, 변경 파일, 테스트 결과를 근거로 기능별 증빙 링크 작성.
4. Replit 브라우저 시연 화면 캡처/녹화는 해당 시점에 실제 촬영된 자료만 연결.
5. 개인정보·비밀번호·세션 쿠키·API 키·실제 학교 내부자료를 외부 공유 전에 비식별화.
6. 이 문서의 원문 발췌와 요약을 섞어 과거의 Claude 입력으로 오기하지 않을 것.
