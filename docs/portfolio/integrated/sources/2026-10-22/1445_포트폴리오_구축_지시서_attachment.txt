# SAFE SCHOOL 개발 기록·AI 프롬프트 아카이브·개발일지·포트폴리오 구축 지시서

## 1. 프로젝트 개요

프로젝트명: **SAFE SCHOOL — 학교 재난안전 통합 업무지원 시스템**

개발 목적: 초·중·고등학교 교직원이 재난 발령, 학급별 대피 보고, 학교 전체 현황 파악, 안전훈련 기록 및 행정문서 작성 등의 업무를 효율적으로 수행하도록 지원하는 웹 애플리케이션 개발

개발 방식:
- ChatGPT: 기획, 요구사항 정리, 설계 검토, 테스트 절차 안내, 오류 분석, 프롬프트 작성
- Claude: 코드 작성·수정, 구현 계획, 코드 분석, 테스트 및 문서화
- Replit: 개발환경, 실행, DB 연동, 실제 테스트 및 배포 환경
- Git/GitHub: 소스코드 버전 관리 및 개발 이력 보존

개발자는 학교 현장의 업무 경험을 바탕으로 요구사항을 정의하고, AI 도구를 활용해 개발과 검증을 수행하고 있습니다.

이번 작업의 목적은 SAFE SCHOOL의 개발 과정을 **검증 가능한 기록물**로 정리하는 것입니다.

**주의: 이번 작업은 문서화 전용입니다. 앱 코드, 데이터베이스, 기존 Git 이력, 시연용 데이터는 수정하지 마세요.**

포트폴리오에는 주요 개발 화면과 기능 흐름을 시각적으로 정리하되, 실제 화면과 개념도를 명확히 구분하세요.

## 9. 작업 순서

먼저 Git 이력, 프로젝트 문서, 코드, 테스트 기록을 조사합니다.

5. 확보되지 않은 자료

### 2단계. 개발 연표 작성

실제 근거를 바탕으로 날짜별 개발 연표를 작성합니다.

### 5단계. 포트폴리오 작성

개발 과정, 주요 기능, AI 협업, 기술적 성과, 검증 결과를 통합합니다.

### 6단계. 최종 검증

모든 수치, 커밋, 날짜, 기능 설명, 이미지 설명을 원본 자료와 대조합니다.
