### 3-2. 주요 개선 내용

**훈련일지 작성 화면**
- PC 넓은 화면에 적합한 레이아웃 적용
- 모바일 1열 레이아웃 유지
- 저장 영역과 문서 출력 영역 분리
- 저장하지 않은 변경사항이 있으면 출력 시 안내

**교직원 담당자 선택**
- 승인된 교직원 명단에서 담당자 선택
- 이름·직책·담임 학급 검색
- 복수 담당자 선택 지원
- 직접 입력 기능 유지
- 학교별 접근 권한 적용

**훈련 참가 인원 관리**
- 교직원 참가 인원
- 학생 참가 인원
- 학생 대피 확인 인원
- 총 참가 인원

위 네 항목을 구분하여 표시합니다.

학생 대피 확인 인원은 보고된 학급을 기준으로 집계하며, 미보고 학급은 0명으로 처리하지 않습니다.

총 참가 인원은 필요한 값이 확인된 경우에만 자동 계산할 수 있도록 개선했습니다.

**훈련일지 HWPX 출력**
- 참가 인원 표 가독성 개선
- 미보고 학급 및 미확정 인원 주석 분리
- 초 단위 훈련 시간 표시
- 붙임 학급별 대피 현황 표 개선
- 40학급 문서의 페이지 분할 및 표 머리글 반복
- 문서 출력 오류 수정

**수정 이력 관리**
- 저장된 문서의 판 번호 표시
- 동일 내용 재저장 시 불필요한 판 증가 방지
- 이전 판 수정 방지
- 동시 수정 충돌 검증
