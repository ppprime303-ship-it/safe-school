# SAFE SCHOOL STEP 3-D — PDF 기준 HWPX 서식 개선 요청

## 1. 작업 목적

STEP 3-D 자동작성 서식 1차 시제품을 검토한 결과, **PDF 시제품의 디자인이 HWPX 시험본보다 깔끔하고 가독성이 높다**고 판단했습니다.

또한 HWPX 시험본이 실제 한글 프로그램에서 정상적으로 열리는 것까지 확인했습니다.

따라서 이번 작업에서는 **PDF의 레이아웃을 기준으로 HWPX 서식의 완성도를 개선**해 주세요.

중요: 이번 작업은 서식 개선 단계입니다. 사용자가 최종 서식을 승인하기 전에는 STEP 3-D 앱 구현을 시작하지 마세요.

## 3. HWPX 서식 개선 요구사항

### A. PDF 디자인과 최대한 동일하게 구성

다음 요소를 PDF 기준으로 개선해 주세요.

- A4 세로 방향, 1페이지 구성
- 상단 중앙 정렬된 문서 제목
- 오른쪽 정렬된 학교명
- 표의 전체 너비와 바깥쪽 여백
- 항목별 셀 높이 및 간격
- 표 테두리와 내부 구분선
- 왼쪽 항목 제목 셀의 병합 구조
- 제목 및 본문 글자 크기의 위계
- 평가 결과 O/X 표시
- 하단 사진 첨부 영역 3칸

특히 HWPX의 표가 한글에서 열렸을 때 흐트러지지 않도록 **셀 너비, 행 높이, 셀 병합과 줄바꿈**을 우선적으로 개선해 주세요.

단순히 PDF를 이미지로 삽입하는 방식은 사용하지 마세요.

**HWPX 안의 제목, 본문, 표와 입력 항목은 한글에서 직접 편집할 수 있어야 합니다.**

### B. 문서 구성 유지

PDF 시제품의 다음 영역을 모두 유지해 주세요.

1. 훈련 일시 및 모의훈련 구분
2. 참가 인원
3. 학급별 대피 현황
4. 역할 및 담당자
5. 훈련 내용과 대피 장소
6. 대피 소요 시간
7. 평가 항목 6개 및 O/X·비고
8. 추후 대피훈련 시 반영 사항
9. 활동 사진 영역 3칸

단, 실제 학교에서 사용하는 기본 비상대피훈련일지는 기존 A4 1쪽 형식을 유지하고, 학급별 상세 대피 현황은 필요시 별도 붙임으로 출력할 수 있도록 향후 확장 가능성을 고려해 주세요.

### C. 디자인 원칙

- 학교 공문서에 적합한 단정하고 전문적인 디자인
- 과도한 색상 및 장식 사용 금지
- 흑백 인쇄 시에도 명확하게 구분되는 표
- 한글에서 수정해도 쉽게 무너지지 않는 구조
- 불필요한 여백 최소화
- 작은 글씨를 지나치게 사용하지 않기
- 정보량이 많아도 주요 항목을 빠르게 찾을 수 있도록 구성

가능하면 PDF와 HWPX의 전체적인 외형이 일치하도록 해 주세요.

다만 HWPX의 구조적 한계로 인해 정확한 복제가 어려운 부분은 별도로 보고해 주세요.

## 4. 자동작성 데이터 정책 유지

이번 개선은 서식 디자인 작업이므로 기존 데이터 정책을 변경하지 마세요.

- 확인된 시스템 기록만 자동 입력
- 미보고 학급은 '미보고'로 표시
- 재적 인원과 실제 참가 인원 구분
- 교직원 참가 인원 임의 생성 금지
- 대피 소요 시간 임의 계산 금지
- 평가 O/X 및 비고는 담당 교사가 직접 확인
- 향후 반영 사항은 담당 교사가 직접 작성
- 실제 학생 이름과 개인정보 사용 금지
- 기존 시연용 가상 데이터 사용

특히 참가 인원이 확정되지 않은 상태에서 전체 참가 인원을 자동 합산하지 마세요.

## 5. 사용자 검토용 파일 제작

개선 작업 후 다음 결과물을 제공해 주세요.

**① 개선된 HWPX 파일**

- 실제 한글에서 열어볼 수 있는 파일
- 제목, 표, 평가 내용 등을 직접 수정할 수 있는 구조
- PDF 시제품의 디자인을 최대한 재현
- 파일명 예시: `SAFE_SCHOOL_비상대피훈련일지_개선본.hwpx`

**② 비교용 PDF 파일**

- 개선된 HWPX의 의도한 레이아웃을 확인할 수 있는 PDF
- 가능하면 실제 HWPX를 렌더링하여 생성
- HWPX 렌더링이 불가능한 경우 별도 템플릿에서 생성한 비교용 PDF임을 명시

**③ 개선 전후 비교표**

다음 내용을 정리해 주세요.

- 표의 셀 병합 및 정렬
- 글꼴과 글자 크기
- 여백과 줄 간격
- 평가표 구성
- 사진 영역
- 한글 편집 가능 여부
- PDF 디자인과 일치하지 않는 부분

**④ 사용자 확인 체크리스트**

제가 한글 프로그램에서 직접 다음 항목을 확인할 수 있도록 안내해 주세요.

- HWPX 파일이 정상적으로 열리는지
- A4 한 페이지로 출력되는지
- 표의 병합과 정렬이 유지되는지
- 글자가 잘리거나 겹치지 않는지
- 평가 항목과 비고를 편집할 수 있는지
- 사진을 삽입해도 표가 크게 무너지지 않는지
- PDF와 전체적인 외형이 유사한지

## 6. 구현 및 검증 원칙

HWPX 파일은 ZIP/XML 구조 검증만으로 호환성이 확보되었다고 판단하지 마세요.

한글 프로그램에서의 실제 열기, 인쇄 레이아웃, 표 편집 가능 여부는 사용자가 직접 검증할 예정입니다.

Claude 환경에서 한글을 실행할 수 없다면 해당 제약을 분명하게 보고해 주세요.

또한 HWPX 파일을 생성하는 코드는 재현 가능한 형태로 보존해 주세요.

향후 SAFE SCHOOL에서 자동작성 문서를 생성할 때 해당 코드를 재사용할 수 있도록 설계하되, **현재는 앱에 연결하지 마세요.**
