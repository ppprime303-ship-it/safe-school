# 04. 기술 아키텍처 및 기능 현황

기준: `step-3d-ui-hwpx` `054a574`(GitHub) — Replit에서는 병합 커밋 `a8eefd2`로 반영(사용자 기록). 아래 그림은 **개념도**이며 실제 화면이 아닙니다.

## 1. 기술 구성 — [확인됨](`package.json`)
| 영역 | 사용 기술 |
| --- | --- |

| 문서 출력 | HWPX(한글) 직접 생성 — 외부 프로그램 없이 ZIP·XML 작성(`server/src/drilllog/hwpx.ts`, `zip.ts`) |

## 2. 구성 개념도
```
[교직원 브라우저(PC·모바일)]
   │  로그인(개인/공용 기기 세션), 학교 선택
   ▼
[React 화면] ─ 상황판·학급 보고·경보함·안내문·훈련일지·교직원/학급 관리
   │  /api (같은 출처, CSRF 방지 헤더)
   ▼
[Express API] ─ 권한 검사(resolveAccess: 소속 학교·승인·기능 권한) ─ 감사 로그
   │
   ▼
[PostgreSQL] ─ 스키마 분리: safeschool_test(자동 테스트) / safeschool_browser_demo(시연)
      DB 제약·트리거: 학교 간 연결 차단, 판 번호 +1 강제, 이력 자동 기록, 삭제 금지
   │
[모의 경보 공급자] → 경보 수집·지역 매칭(실제 행정안전부 API 미연동)
[HWPX 생성기] → 비상대피훈련일지 내려받기(사용자가 한글에서 마무리·K-에듀파인에 직접 첨부)
```

## 4. 역할과 권한 — [확인됨](`shared/permissions.ts`, 마이그레이션 제약)
| 구분 | 권한 | 지정 |
| --- | --- | --- |
| 학교 관리자(기존) | 발령·종료, 상황판, 교직원·학급·소재지·업무 관리, 훈련일지 열람 | 학교 등록 시 |
| 교장(직책, 1명) · 교감(직책, 최대 2명) | 발령·종료, 상황판, 훈련일지 열람 | 기관 확인 후 플랫폼 운영자 등록(앱에서 지정·회수 불가) |
| 안전업무 담당(업무, 다수·겸임) | 발령·종료, 상황판, 훈련일지 열람·작성 | 앱에서 지정(자기 지정 불가) |
| 앱 운영담당(업무, 다수·겸임) | 교직원·학급·소재지·업무 관리 | 앱에서 지정 |
| 담임교사 | 담당 학급 대피 보고 | 학급 배정 |
| 일반 교직원 | 경보함, 배정 시 학급 보고 | 가입 승인 |

## 5. 기능별 상태
표기: ● 구현·자동 검증 / ◐ 구현, 모의 데이터로만 확인 / ○ 계획 / ✕ 의도적으로 만들지 않음

| 기능 | 상태 | 비고·근거 |
| --- | --- | --- |
| 로그인·이메일 인증(시험 환경은 모의 발송)·개인/공용 기기 세션 | ● | STEP 2 |
| 학교 등록·학교알리미 정보 연동·교직원 가입 승인 | ● | `2535b49`, `448370d`. 학교알리미 실제 응답 필드는 `docs/test-record.md` 기록 참조 |
| 학급·재적 관리(변경 사유) | ● | STEP 2 |
| 재난 발령·종료(훈련/실제 구분, 복합 유형, 중복 409) | ● | STEP 3-A |
| 담임 모바일 대피 보고(미확인 자동 계산, 수정 이력) | ● | STEP 3-A |
| 상황판(5초 갱신, 미보고·미확인·부상) | ● | STEP 3-A. 통신 실패 시 수치 보존은 모의 서버로만 시험 |
| 공식 경보 수집·지역 매칭·재송출 묶음·경보함 | ◐ | 모의 공급자만. 실제 공급자 어댑터 없음 |
| 경보 연결 안내문 작성·예시문 21개·판 관리·취소본 재사용 | ● | STEP 3-C. 실제 발송 없음 |
| 직책·업무 권한(겸임) | ● | STEP 3-D |
| 비상대피훈련일지 자동작성·수정 이력·원본 변경 알림 | ● | STEP 3-D |
| HWPX 출력(본문 1쪽 + 붙임) | ● | 한컴오피스 열람 확인(사용자 기록) |
| 교직원 명단에서 담당자 선택 | ● | `054a574`, 이름·직책·담임 학급만 제공 |
| 황사·미세먼지 일지, 재난대응훈련 계획서 | ○ | 설계 문서에서 후속 대상으로 분류(`docs/step3d/step3d-design.md`) |
| 안전교육·시설 점검 | ○ | 후속 검토 |
| 학부모 외부 발송, 경보에 따른 자동 발령, K-에듀파인 자동 결재·업로드 | ✕ | 사용자 지시로 제외 |
