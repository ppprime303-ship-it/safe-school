# 02. AI 프롬프트 기록집

## 기록 원칙
- **원문**은 저장소의 원문 파일에 글자 그대로 보존되어 있으며, 아래 표에는 **위치와 첫 줄(제목)** 만 옮깁니다. 첫 줄 외의 문장은 이 문서에서 다시 쓰지 않았습니다.
- 원문이 없는 경우 **'프롬프트 원문 미확보'** 로 표시하고, 확인 가능한 작업 지시의 요지를 AI 요약·커밋·문서에서 따로 적습니다(요지는 원문이 아님).
- 경로 약어: `S20` = `docs/portfolio/sources/`, `S21` = `docs/portfolio/2026-10-21/sources/`, `S22` = `docs/portfolio/integrated/sources/2026-10-22/`
- 도구 표기: 사용자 → Claude(사용자가 Claude에 입력), ChatGPT 작성(ChatGPT가 쓴 글을 사용자가 Claude에 전달), ChatGPT 대화(사용자가 ChatGPT에 입력)
