## 6. 한계와 미검증
- 모바일 문서 미리보기는 가로 스크롤이 필요함
- 모바일의 모든 입력·저장 동작을 수동으로 검증하지 않음
- 실제 학교 운영환경 검증·사용자 평가 미실시, 업무경감 시간 미측정
- 공식 경보는 모의 공급자로만 확인(실제 API 미연동)
- 통신 장애 시 상황판 수치 보존은 모의 서버로만 시험
- 보안 점검은 개발 단계 테스트(권한·격리·입력 검증) 수준이며 외부 인증·침투 시험 없음
- 10/22 Replit 실행 로그 원문은 이 저장소에 없음(사용자 보고 수치만)
