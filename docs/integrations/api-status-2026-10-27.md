## 1. 인증 정보 설정 여부(학교 PC, 값 비공개)
`SCHOOLINFO_API_KEY`, `MOIS_CBS_SERVICE_KEY`, `MAIL_API_KEY`, VAPID·나이스·문자·카카오 관련 변수 모두 **미설정**(프로세스·사용자·시스템 환경, 저장소 `.env` 없음).
운영 VPS `pilot.env`의 설정 여부는 **확인 필요**(SSH 필요, 오늘 접속하지 않음).

## 3. 장애 격리·표시(PHASE 5 관점, 현재 코드)
| 항목 | 현재 |
| --- | --- |
| 외부 API 장애가 전체 장애로 이어지는가 | 학교알리미: 실패 시 마지막 목록으로 검색(stale). 경보 수집: 별도 주기 작업, 실패는 기록만 하고 다음 주기 재시도. 학교 재난 발령·보고는 외부 API와 무관 |
| 출처·마지막 갱신 시각 표시 | 학교 검색: stale 경고 있음. 공시자료: stale 반환. **경보함: 수집 상태·마지막 성공 시각 표시 없음(보완 필요)** |
| 공식 경보 오인 방지 | 경보함에 '공식 시스템 대체 아님' 안내, 모의 경보 '모의' 표시, 원문 그대로, 자동 발령 없음 |
| 평가 계정의 외부 데이터 조회 | 공개 데이터(학교 정보·경보)만 — 평가 계정 개인정보를 외부로 보내지 않음. 평가 환경에서는 모의 경보 사용 |
