## 키 연결과 소량 확인

키는 `%USERPROFILE%\devtools\postgresql16\secrets\`(사용자 전용 권한)에만 둡니다. 저장은 같은 폴더 위의 `set-api-key.ps1 -Name 이름`(숨김 입력)입니다. 기상특보 이름은 `KMA_WARNING_SERVICE_KEY`입니다.

| 도구 | 동작 |
|---|---|
| `check-api-keys.sh` | 키 파일 설정 여부만 true/false |
| `scripts\preview\api-verify.ps1 -Api schoolinfo\|neis\|mois\|kma` | 해당 키 하나만 이 프로세스에 넣어 1회 호출. DB 접속 없음. 결과 코드·건수·필드 이름만 출력 |
| `scripts\preview\preview-start-api.cmd` | 승인·응답 확인 후 학교알리미·기상특보 키를 미리보기 프로세스에만 연결. 재난문자 수집은 켜지 않음 |

| `preview-start.ps1 -WithApiKeys -CollectKma` | 호출 승인·마이그레이션 적용 후에만. 미리보기 DB에 기상특보를 저장하고 교직원 안내를 켬 |

`preview-start.cmd`는 이전처럼 키를 모두 지우고 시작합니다. 키 파일 권한은 현재 사용자만 읽기·쓰기(3개 파일 확인), 저장소 밖이라 Git 대상이 아닙니다.

## 나이스 HTTP 500 분석

10월 27일 8회 모두 WebtoB 단계의 HTML 500이었고, 틀린 키·없는 학교·한글 없는 요청에서도 같았습니다. 나이스 결과 코드까지 가지 못했으므로 어댑터 결함이나 키 문제의 근거가 없습니다. 요청 주소는 공식 명세와 일치합니다. 제공기관 장애, 비브라우저 요청 차단, 학교망 송신 IP 중 어느 것인지는 미확인입니다. 헤더 위장으로 우회하지 않습니다. 실제 응답 전까지 `NEIS_CONTRACT.verified=false`입니다.

## 긴급재난문자 명세 대조

공개 페이지(safetydata.go.kr 데이터 228, 공공데이터포털 15134001)에서 확인한 것은 `CRT_DT`, `MSG_CN`, `EMRG_STEP_NM`, `RCPTN_RGN_NM` 필드 이름뿐입니다. 요청 주소·인자·`SN`은 활용 신청 후 열람 범위로 미확인입니다. 공유플랫폼 '오픈 API' 탭의 명세를 사용자가 전달해 주거나 호출 승인이 있어야 대조할 수 있습니다. `MOIS_CBS_CONTRACT.verified=false`를 유지하고, Beta는 이 상태에서 수집을 켜면 시작을 거부합니다.

## 교직원 자동 안내(가짜 응답으로만 검증)

공식 API → 서버 수집(`official_alerts`) → 학교 지역 판정(`school_alert_matches`) → 교직원별 미확인(`alert_reads`) → 30초 조회 안내 창. 브라우저는 저장된 자료만 읽습니다.

| 규칙 | 내용 |
|---|---|
| 우선순위 | 경보·중대경보·위급·긴급은 우선, 주의보·안전안내는 일반. 예비특보는 수집하지 않음(경보함 기상청 현황 원문으로만) |
| 재안내 | 정정·변경은 다시 안내, 연장은 이미 확인했으면 안내 안 함 |
| 해제 | 안내하지 않고 경보함의 기존 경보를 '해제됨'으로 갱신 |
| 사건 진행 중 | 창을 띄우지 않고 화면을 막지 않는 안내 줄 표시(대피 보고 우선) |
| 경계 | 학교 재난 자동 발령 없음, 대피 권고 문구 없음, 경보함에서 읽으면 확인으로 처리 |

기상특보 수집·안내에는 마이그레이션 `20261103000000_kma_warning_provider`와 `ALERT_PROVIDERS=kma_warning`이 필요합니다.

## 기상특보 구현 근거

공식 활용가이드 `기상청21_기상특보 조회서비스_오픈API활용가이드_260601`과 특보구역코드 파일을 대조했습니다.

| 항목 | 내용 |
|---|---|
| 호출 | `getPwnCd` 최근 7일 발표분(쪽당 500건, 최대 3쪽) + `getPwnStatus` 1회 |
| 7일 이전 특보 | `getPwnStatus` 발효현황 원문의 인천 관련 줄을 그대로 표시. 수집을 켠 뒤에는 발표 기록이 DB에 남아 기간에 묶이지 않음 |
| 상태 | 구역·종류·강도별 마지막 발표 기준. 1·3·6·7 발효, 2·8·취소·전체해제 시각 경과는 해제 |
| 지역 근거 | [기상청 보도자료 2026-05-12](https://www.weather.go.kr/kma/flexer/html/press/2026/05/12/ATC202605121411572_3597bb78-aff4-498c-99e1-ed62bf0d0bf5.hwp.files/Sections1.html): 인천영종=중구 영종 8개 동, 인천남부=동·미추홀·연수·남동구와 중구(영종 제외), 인천북부=서·부평·계양구 |
| 개편 구 | 영종구→인천영종, 제물포구→인천남부, 서해구·검단구→인천북부(옛 구 경계로 판단, 실제 응답 구역명 확인 전) |
| 미판정 | 옛 '중구' 주소, 서해5도·우도 소속 학교는 면 단위 주소가 필요해 '포함 여부 확인 필요'(관리자만 안내) |
| 미지원 | 인천 외 지역은 표시하지 않고 안내 |
| 장애 | 재시도 없음, 5분 캐시, 실패 후 1분 재호출 없음, 마지막 정상 자료는 '이전 조회 자료'로 표시 |
| 분리 | 저장·알림·재난 발령 없음. 새 테이블·마이그레이션 없음 |

**확인 전 가정:** 가이드 예시는 XML뿐이라 JSON 구조는 같은 형태로 가정합니다. 7일보다 앞서 발표되어 이어지는 특보는 나오지 않을 수 있어 화면에 조회 기간을 적습니다. `KMA_WARNING_CONTRACT.verified=false`이며 화면에 '시범 조회'로 표시합니다.

## 안전장치
- 외부 정보는 학교 재난을 자동 발령하지 않고 교직원 알림도 만들지 않습니다.
- 키는 서버 환경변수만 사용하며 화면 코드와 수집 오류에 남지 않습니다.
- Beta는 명세 미확인 재난문자 수집과 모의 경보를 켜면 시작을 거부합니다.
- 외부 장애 중에도 발령·학급 보고·상황판·종료는 동작합니다(`step-a-alert-feed` 테스트).
