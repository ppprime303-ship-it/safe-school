공공데이터포털 [기상청_기상특보 조회서비스](https://www.data.go.kr/data/15000415/openapi.do): 기상청 제공, REST(JSON·XML), 무료, 자동승인, 개발계정 10,000건. 특보 목록·통보문·특보 현황 등을 제공합니다. 포털의 활용가이드 압축 파일을 직접 대조하지 않았으므로 호출 주소와 응답 항목은 확정하지 않았습니다. 지점코드(`stnId`)와 학교 지역의 대응 규칙도 필요합니다.

## 안전장치
- 외부 정보는 학교 재난을 자동 발령하지 않고 교직원 알림도 만들지 않습니다.
- 키는 서버 환경변수만 사용하며 화면 코드와 수집 오류에 남지 않습니다.
- Beta는 명세 미확인 재난문자 수집과 모의 경보를 켜면 시작을 거부합니다.
- 외부 장애 중에도 발령·학급 보고·상황판·종료는 동작합니다(`step-a-alert-feed` 테스트).
