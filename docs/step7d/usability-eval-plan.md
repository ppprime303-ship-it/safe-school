# STEP 7-D 가상 학교 교직원 사용성 평가 계획서

작성 2026-10-27 · 평가 예정 2026-10-28(수) · 상태: **평가 환경 위치·배포 방식 결정 대기**

## 1. 목적
실제 학교 시범운영 전에, 교직원이 **가상 학교 계정**으로 핵심 업무(훈련 발령 → 학급 보고 → 상황판 확인 → 종료 → 훈련일지)를 도움 없이 할 수 있는지 확인하고, 막히는 지점과 개선 요청을 모읍니다.
- 기능의 정답 여부보다 **찾기·이해·실수**를 봅니다. 권한 차이(겸임)가 화면에서 이해되는지도 봅니다.
- SAFE SCHOOL은 학교의 공식 재난 대응·경보 시스템을 대체하지 않습니다. 평가 시작 때 안내합니다.

## 2. 원칙
| 원칙 | 방법 |
| --- | --- |
| 실제 개인정보 없음 | 가상 학교 2곳·가상 계정 8개만(`judge-…@judge.safeschool.invalid`). 참여자 이름·이메일을 앱·기록지에 쓰지 않음(참여자 코드 P1~P8) |
| 운영과 분리 | 운영 VPS·시범운영 DB(`safeschool_prod_pilot`) 사용 금지. **평가 전용 DB 1개**에 심사 스키마 이름(`safeschool_prod_judge`)으로 구성 — 기존 심사 도구의 안전장치(시범운영 거부·DB 권한 검사·실제 학교 섞임 거부)를 그대로 받기 위함 |
| 인증 우회 없음 | 계정은 운영자 셸 도구(`npm run judge:setup`)로 미리 만듦. 앱에 우회 기능 추가 없음. 가입·이메일 인증은 평가 범위 밖 |
| 안전 | 화면 캡처는 가상 데이터만. 실제 상황 발령(실제 모드) 금지 — 모의훈련만 |

## 3. 평가 환경(결정 필요)
| 항목 | 요구 사항 |
| --- | --- |
| DB | 평가 전용 DB(예: `safeschool_eval_<날짜>`) — 평가 후 DB째 삭제(`eval-data-reset.md`) |
| 앱 | 98ca057 + 이번 변경 빌드. `NODE_ENV=production`, `DEPLOY_PROFILE=production`, `DEPLOY_DB_SCHEMA=safeschool_prod_judge`, `SESSION_SECRET`(32자 이상, 평가용 새 값), 모의 경보 `ALERT_PROVIDERS=mock`·`ALERT_MOCK_FEED=deploy/judge/mock-alerts.json` |
| 접속 | 참여자 기기에서 접속하려면 그 기기에서 앱 주소가 열려야 함. **학교 PC 로컬(127.0.0.1)이면 그 PC 브라우저에서만 가능.** 교내망에 여는 것(0.0.0.0·방화벽)은 별도 승인 사항 |
| 위치 후보 | ① 학교 PC 로컬(같은 PC에서 교대로) ② 별도 평가 서버(운영 VPS 아님) ③ Replit 심사 배포(11월 이후) — 사용자 결정 |
- 결정 전까지 데이터 생성·서버 실행은 하지 않습니다.

## 4. 참여자·역할
| 계정 | 학교 | 역할(겸임) | 핵심 과제 |
| --- | --- | --- | --- |
| a1 | A 시연초(가상) | 앱 운영담당 + 1학년 1반 담임 | 학급 보고, 교직원·업무 화면 |
| a2 | A | 안전업무 담당 | 발령·종료·훈련일지 작성 |
| a3 / a4 | A | 교장 / 교감 | 상황판, 발령·종료, 훈련일지 열람 |
| b1 | B 시연중(가상) | 앱 운영담당 | 교직원·학급·업무 화면 |
| b2 | B | 안전업무 담당 + 1학년 1반 담임 | 발령부터 보고·훈련일지까지 혼자 |
| b3 / b4 | B | 교장 / 교감 | 상황판, 열람 |
- 참여자 수가 적으면 한 사람이 같은 학교 계정 2개를 순서대로(예: a2 → a1) 맡습니다.
- 계정별 과제: `usability-scenarios.md`

## 5. 진행(약 60분)
| 시간 | 내용 |
| --- | --- |
| 5분 | 안내: 목적, 가상 데이터, 공식 시스템 아님, 기록 방법(이름 미기록), 언제든 중단 가능 |
| 5분 | 계정 배부(종이 카드, 평가 후 회수), 로그인 |
| 30분 | 시나리오 수행(학교별 동시 진행). 진행자는 도와주지 않고 관찰(막혀서 3분 넘으면 힌트, 기록) |
| 10분 | 자유 사용 + 오류·개선 요청 기록 |
| 10분 | 짧은 설문(과제별 쉬움 1~7) + 의견 |

## 6. 측정
- 과제 성공: 혼자 성공 / 힌트 후 성공 / 실패
