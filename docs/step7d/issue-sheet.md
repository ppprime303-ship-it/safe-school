# STEP 7-D 오류·개선 요청 기록지

평가 중 발견한 오류와 개선 요청을 한 줄에 하나씩 적습니다. **개인정보·비밀번호를 적지 않습니다.** 캡처를 붙일 때는 가상 데이터만 보이는지 확인합니다.
